# Final submission checklist

Verified deadline: **23 October 2026, 12:00 PDT = 24 October 2026, 00:30 IST**. Aim to finish well before it.

- Full runnable source on GitHub with MIT license, lockfile, setup instructions and sample assets.
- Code URL points to the new coach version; judges must not land on the unchanged original branch.
- Public YouTube/Vimeo demonstration under three minutes showing actual functioning behavior.
- English description, significant-update explanation, track selection and product feedback.
- Select Alexa+ simulated experience / MCP route. Do not claim unimplemented Amazon integrations.
- Include actual screenshots and test report. Keep private documents, local data, runtime binaries, model weights and credentials out of source publication.
- Review the Devpost draft, then complete the final submission. Registration alone is not a project submission.
- Verify Devpost shows a submitted entry and preserve its confirmation/link.
