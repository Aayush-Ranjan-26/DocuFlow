# Third-party components

Dependencies are installed from npm via the lockfile; their package license files govern redistribution. No dependencies or model weights are embedded in the source ZIP.

- @modelcontextprotocol/sdk: official TypeScript MCP SDK, MIT. https://github.com/modelcontextprotocol/typescript-sdk
- express: HTTP server, MIT. https://github.com/expressjs/express
- mammoth: DOCX extraction, BSD-2-Clause. https://github.com/mwilliamson/mammoth.js
- pdf-parse: PDF extraction, Apache-2.0; PDF.js retains its notices. https://github.com/mehmet-kozan/pdf-parse
- zod: input validation, MIT. https://github.com/colinhacks/zod
- Ollama: separately installed runtime, MIT. https://github.com/ollama/ollama
- llama.cpp: alternative CPU runtime, MIT; bundled runtime dependencies retain their included notices. https://github.com/ggml-org/llama.cpp
- Qwen2.5-1.5B: separately downloaded model, Apache-2.0. https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct

The interface uses system fonts and original CSS. No stock imagery, music or footage is used. The fictional syllabus and extraction fixtures were authored for this project.
